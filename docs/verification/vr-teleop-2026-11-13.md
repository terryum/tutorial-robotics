# Ubuntu optional VR curriculum — development verification

Native Ubuntu 24.04.5 x86_64; Linux development only. Mac portability is covered
by dependency-light contracts, but no native Mac run was performed this session.
No learner completion, hardware command, firmware change or remote push.

Added core-teleop-01 after core-04, plus sim-teleop-01 (physical input remains
reader_test_required), sim-teleop-02 and sim-enlight-06 as optional lessons.
Existing VR-free prerequisites and named robot paths remain available.

The v2 input contract preserves raw clocks/frames, names, side identity, sources,
calibration and clutch/deadman. The command sink latches at exactly 100 ms and
requires a fresh release, local rearm and fresh press. The VUT receiver bounds
its work and never waits for a complete packet. Tests cover fragmented headers
and payloads, disconnect, invalid conventions, NaN, side swaps, calibration,
sequence rollback, expiry and reconnection. Socket tests require native local
socket permissions; the sandbox initially denied socketpair sends.

Three synthetic Enlight MuJoCo episodes, each sixteen 50 Hz frames, were stored
with camera/state/applied action and reloaded. Discarded and aborted manifests
are separate. Wrist IK uses the Enlight model and limits. Gripper tasks remain
unavailable. Model-bound external BC rejects episode leakage and incompatible
observations/actions. Four BC updates changed weights (L1 3.1751172475), saved
policy reload error was 0, and all weights were finite. Independent evaluation
achieved 0/20 targets; performance_verified=false. Collection TCP error was at
most 0.00362091 m for this small synthetic movement. These are software results,
not human demonstrations or hardware tolerances.

Public regression: 223 passed, three optional skips, eight subtests. Shared
core: nine passed, eight subtests. Repository/release checks, Ruff, mypy, strict
MkDocs and credential/public-boundary scans passed. Final affected checks are
recorded by the local development commit and private compatibility handoff.

Official Hub v1.0.3 beta x86_64 archive SHA256 matched its release checksum and
was extracted only into ignored .local/vendor. Readelf dependency inspection did
not launch vendor software. The separately cloned SDK candidate was exactly
8685112780734c2513c66d53b9eb104db47afcf9. Its IPC is incompatible with the Hub's
included VUT SDK: see [setup and source links](../en/setup/vr-teleop.md).
No HTC EULA acceptance, udev changes, vendor daemon or device setup occurred.

Actual Quest/MANUS/VIVE USB devices were absent. Pending: HTC review, native
SDK negotiation, model/firmware/Integrated entitlement, Linux maps and mounting
transforms, Quest alignment, simultaneous 60-second measurements and human
