# Learning Method

Each lesson report must answer five questions.

1. **What physical quantity changed?** Position, velocity, torque, contact force, reward, action chunk, or latency.
2. **What equation or algorithm governed it?** Include units and assumptions.
3. **Where is it represented in code?** Name the module, class, function, and data shape.
4. **What did the experiment show?** Use a plot, video, and a numerical metric.
5. **Why does this matter in a cosmetics factory?** Connect to cartons, caps, pumps, trays, weighing, inspection, or human coexistence.

Do not treat a successful animation as understanding. At least one controlled parameter modification is required for conceptual tutorials.
