# Legacy tutorial URLs

The v1 curriculum lives in the machine-readable [catalog](../curriculum/catalog.json) and bilingual [English](../docs/en/index.md) / [한국어](../docs/ko/index.md) indexes.

Files below this directory are one-major-release redirects. Legacy commands such as `pal lesson run T00 --headless` resolve to canonical IDs and print a deprecation warning. New documentation and code must use `core-*`, `sim-*`, or `hw-*` IDs.
