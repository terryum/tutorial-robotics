# Bilingual terminology

| English | 한국어 | Meaning |
|---|---|---|
| joint position | 관절 위치 | radians for rotational joints |
| torque | 토크 | N m, not position increments |
| world frame | 월드 좌표계 | explicitly named reference frame |
| Jacobian | 자코비안 | local velocity map with declared dimensions |
| saturation | 포화 | clipping to specified limits |
| checkpoint | 체크포인트 | saved optimizer/model state, not completion |
| independent evaluation | 독립 평가 | held-out rollout with declared criterion |
| mock policy | 모의 정책 | protocol exercise, not trained VLA |
| command sink | 명령 차단 수신기 | offline receipt with no physical output |
| verification badge | 검증 배지 | publication status independent of local run |
| capability-unavailable | 역량 사용 불가 | missing dependency/runtime, never pass |
| scaffolded | 골격만 구현 | no complete executable lesson |
