# 한국어 오프라인 교재 검증

2026년 11월 24일 Apple Silicon Mac에서 공개 Core 캐시를 사용해 개발 검증을 실행했습니다. 운영체제와 Python·MuJoCo 버전, 기존 수업의 구현과 대표 산출물 SHA-256은 [Mac 수치 요약](robotics-ko/mac-results.json)에 있습니다. 대표 수업은 씨드 7, 표본 수 64, 변형 계수 1.0으로 실행했습니다. 개발 러너는 학습 완료 요건만 분리하고 플랫폼, 의존성, 모델 지문, 수치와 렌더링 검사를 적용했습니다. BC의 입력은 같은 배치에서 생성하고 검사한 시연 기록을 사용했습니다.

Mac 검증에는 ROS 2 Jazzy와 Isaac Sim·CUDA에 필요한 조건이 없었습니다. 해당 카탈로그 실행은 차단 결과를 남겼습니다. WS2에서는 [워크스테이션 런북](../setup/WS2_ROBOTICS_KO_VERIFY.md)에 따라 PhysX 추종·접촉, 초기 자세 RGB-D, 짧은 정책 학습과 독립 평가, NVIDIA 모델 추론을 검증합니다. 장비 입력과 실제 로봇은 별도의 현장 실습에 해당합니다.

## 공통 기초 보강 검증

2026년 11월 24일 Apple Silicon Mac에서 Python 3.12.13, NumPy 2.5.2, SciPy 1.18.1, Matplotlib 3.11.1로 두 조건씩 실행했습니다. 행동 복제의 분할 검산과 독립 평가는 MuJoCo 3.12.0에서 다시 생성한 Enlight 시연과 평가 기록을 사용했습니다.

| 검증 | Mac 실행 결과 |
| --- | --- |
| 진자 LQR | R=0.1의 리카티 잔차는 6.56×10⁻¹⁴였고 PD와 LQR의 폐루프 고유값 절댓값 최댓값은 0.972와 0.863이었습니다. 같은 비용식에서 PD 21.185, LQR 11.917이었습니다. R=0.5에서 LQR의 최대 토크는 1.596에서 0.604 N·m로 줄었고 정착 시간은 0.66에서 0.88 s로 늘었습니다. |
| 각도 센서 칼만 필터 | 단절 표본 25개에서 보정이 생략됐고 공분산은 대칭이며 양의 준정부호였습니다. 각도·각속도 RMSE는 예측만 썼을 때 0.09404 rad·0.40782 rad/s, 칼만 필터에서는 0.00875 rad·0.06290 rad/s였습니다. 마지막 단절 시각의 두 표준편차는 단절을 없앤 실행의 같은 시각보다 컸습니다. |
| 격자의 가치 반복과 Q-learning | 기본 미끄러짐 10%에서 시드 7, 21, 42 모두 출발점 기대 수익 0.72465를 얻어 가치 반복 기준과의 차이가 0.02 이내였습니다. 30%에서는 기대 수익이 0.51864로 내려가고 첫 행동이 동쪽에서 북쪽으로 바뀌었습니다. |
| Enlight BC 분할 검산 | 프레임 분할에서 중복 시연 25개, 에피소드 분할에서는 0개였습니다. 기존 평가의 보류 검증·테스트 행동 MSE는 0.04854·0.06400이었고 독립 폐루프 도달은 20/20이었습니다. |
| 독립 검토와 HTML | 수식과 수치, 시계열, 손계산, 내장 그림을 대조했습니다. Chrome 158.0.8127.89에서 네트워크를 끈 상태로 1440×950과 390×844를 확인했습니다. 다섯 장의 목차·복귀 링크, 그림 12개, 이동 로봇에서 칼만 필터로 이어지는 링크가 작동했고 외부 리소스 요청은 0건이었습니다. 모바일의 장 간 링크는 브라우저 DOM으로 활성화해 확인했습니다. |

교재를 재생성하려면 저장소 루트에서 Docs 환경으로 빌더를 실행합니다.

```bash
uv sync --locked --extra docs
uv run --no-sync python scripts/build_robotics_ko.py
```

생성 파일은 `outputs/robotics-ko/index.html`입니다. [교재 원고](robotics-ko/index.md)에서 각 실습의 명령과 비교 조건을 확인할 수 있습니다.
