이 교재는 기본 Python 문법을 아는 독자를 대상으로 합니다. 진자의 움직임을 예측하는 데서 시작해 로봇 팔을 제어하고, 카메라로 물체를 찾고, 이동 로봇의 자세와 지도를 추정합니다. 같은 관측·계획·제어 구조를 워크스테이션과 장비 준비에 이어서 적용합니다.

실습마다 먼저 결과를 예측하고, 코드에서 수식에 대응하는 줄을 찾습니다. 실행 뒤 기록 파일의 수치를 읽고 변수 하나만 바꿔 비교합니다. 명령은 저장소 루트에서 실행합니다. Mac에서는 기존 Core 환경의 `.venv/bin/python`을 사용할 수 있습니다. 사용 중인 Python 환경에 저장소 패키지와 Core 의존성이 설치되어 있어야 합니다.

이 HTML은 브라우저에서 바로 열 수 있습니다. 실습 명령은 터미널에서 실행합니다. OpenGL 그림을 생성하는 MuJoCo 실습은 호스트의 그래픽 컨텍스트를 사용합니다. Enlight 자산이 없으면 `pal assets fetch flexiv-description`으로 고정 공개 자산을 준비하고 다시 실행합니다. FR3 선택 경로의 번들은 `mujoco-menagerie`입니다.

| 결과 표기 | 의미 |
| --- | --- |
| Mac 직접 실행 | Mac에서 코드와 결과 파일을 검증했습니다. |
| 기존 기록 | 이전 공개 검증 기록이나 연습 경로를 가리킵니다. |
| 합성 입력 재생 | 생성한 입력을 재생해 관측 형식과 차단 동작을 확인했습니다. |
| 현장 확인 대기 | 해당 환경에 설치된 런타임 또는 장비에서 검증해야 합니다. |

교재를 다시 만들 때는 Docs 의존성을 준비한 환경에서 아래 명령을 실행합니다. 워크스테이션에서 새 검증 요약을 저장한 뒤에도 같은 명령을 사용합니다.

```bash
uv sync --locked --extra docs
uv run --no-sync python scripts/build_robotics_ko.py
```
