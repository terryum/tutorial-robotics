# Public Curriculum Baseline

The public learning path uses FR3 for manipulator control, Unitree G1 for
floating-base motion and imitation, Wuji Hand 2 and Sharpa Wave for dexterity,
and ALOHA for bimanual imitation learning. Transfer is through shared task,
observation, action, dataset, evaluator, and deployment interfaces—not copied
gains or assumed dynamic equivalence.

Every external repository and model must be pinned to an immutable revision.
When redistribution is not allowed, store only the source URL, revision,
license, checksum, and adapter code.
